# Platzwerk Statistik-Video

Animiertes Statistik-Video (Februar 2025 bis Oktober 2026) in Glasoptik.

- `Platzwerk_Statistik_Querformat.mp4`: 1920×1080, für Fernseher, Beamer, Laptop
- `Platzwerk_Statistik_Hochformat.mp4`: 1080×1920, fürs Handy

Quellen: `index.html` (Animation, alle Zahlen stehen oben im Script), `music.py` (Musik), `render.js` und `build.sh` (Video neu bauen, braucht Node mit Playwright, ffmpeg, Python mit numpy und scipy).
Vorschau im Browser: `index.html` öffnen, fürs Hochformat `index.html?fmt=port`.
